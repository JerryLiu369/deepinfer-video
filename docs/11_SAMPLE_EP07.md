# 11 样板：EP07 SWA 有界重放

EP07 是试点集，也是全系列的样板。`examples/ep07_sample/` 里放着它的一套"已经做对了的"中间产物，用来校准风格、格式和核验深度。新集的方案、脚本、分镜写完后，先和这里对一遍。

> 样板只覆盖 EP07 的前 5 分钟（节拍 1–11）。这样做是故意的：样板的用途是示范**写法**，不是替试点集把活干完。P2–P9 仍要为 EP07 完整走一遍，样板里的条目和句子可以直接沿用，但要重新过关卡。

## 1. 样板里有什么

| 文件 | 阶段 | 看什么 |
| --- | --- | --- |
| `facts/EP07.yaml` | P2 | 11 条事实：A 级怎么写证据和摘录、B 级怎么写条件、E 级（示意计算）怎么挂 calc、`verified_with_caveat` 的 caveat 怎么写 |
| `facts/GLOBAL.yaml` | P2 | 跨集事实的放法 |

## 2. 事实账本：样板做对了什么

1. **A 级必须回到源码行。** F07-05 同时挂了 `environ.py`、`model_runner.py` 和 `README.md` 三处，`quote` 是原文那一行 assert，不是转述。
2. **B 级写清"谁说的"。** F07-02、F07-03 都来自 `doc/inference_deployment_qa.md`。`conditions` 里写明"DeepSeek 官方文档的说法"，并指出文档**没写**的东西（2,560 的推导）。脚本因此只说"DeepSeek 在部署问答里算过"，不替文档补推导。
3. **口径冲突本身就是素材。** F07-04 的 caveat 记下"文档说最后 128 个，代码要求 ≥ 134，README 设 140"。这条没有被"统一"掉，而是变成了 S08 一整个镜头。
4. **预先堵住常见的错误说法。** F07-05 的 caveat 写着"不要写成 140 = 128 + 2×6"。看到一个能凑出来的算式时，先问"代码里有没有这样写"。
5. **示意数字也进账本。** F07-10 是 E 级：输入长度是假设的，"行·层"不等于 FLOPs。它挂了 `calc/EP07_rows.py`，`caveat` 写出这笔账忽略了什么（F07-08 的第 20 层全长处理）。
6. **没核完就明说。** F07-11 只凭知识库笔记 R07#22 入账，`verified_by` 写着"KB note only"，caveat 要求 P2 打开技术报告原文复核。样板宁可把这条标出来，也不假装已经核过。

## 3. 方案：样板做对了什么

- **三句话可检验。** 每句都带事实 ID。viewer 的复述和 H3 的自测题都拿它对照。
- **冷开场 A/B 风格明显不同。** A 用数字反差，B 用日常类比。盲选理由写在方案里：B 的"读书"类比在"层叠起来"这一步会误导。被淘汰的版本里有用的一句（"假装前面什么都没有"）挪到了后面。
- **前置概念表不只列已讲过的。** 投机解码在 EP09 才讲，但 EP07 的"回退预算 6"离不开它。方案在节拍 14 用一句话加一张图补上，并预告 EP09。
- **aha 后马上"降温"。** S09 给出"约 50.7%"，S10 立刻指出这笔账简化了什么，并明说"计算量减半 ≠ 速度快一倍"。每个 aha 都要配一个防误解的镜头。
- **贯穿案例的取舍。** 系列的"第五轮请求"约 6 万 token，样板的示意账用 1 万 token，因为口播更好算。完整一集可以在 S09 之后加一句"换成第五轮请求的 6 万 token，比例更接近一半"，前提是 P2 用 calc 脚本算出来并入账。

## 5. 分镜：样板做对了什么

- 每个动作都挂在脚本里真实存在的 cue 上（21 个 cue，分镜里的 `until()` 与之一一对应）。写分镜时发现 S01 缺一个 cue，就回到脚本加了 `[#keep]`，而不是在分镜里写"大约 2.5 秒后"。
- 示意图都写了示意声明，例如"8 格代表 128 个 token"。
- S09 是按比例图，比例来源写明 `calc/EP07_rows.py`。
- S08 的代码卡用原文摘录和真实路径行号；分镜里写明"太长就按原文换行，不改写"。
- 三个新组件（`LayerStack`、`AttentionMatrix`、`Scale`）写成"参数 + 外观 + 用在哪"，animator 可以直接实现。
- "全集一致性"一节把本集新定的画法（encoder/decoder 配色、被截掉的行变灰）登记下来，后面的集要遵守。

## 7. 用样板校准时常见的偏差

| 偏差 | 表现 | 处理 |
| --- | --- | --- |
| 照抄样板句式 | 每集开场都是"一个 X 的模型，……可在 DeepInfer 里……" | 样板示范的是"数字反差"这个方法，不是句子。冷开场每集换一种手法 |
| 账本比样板浅 | A 级没有 `quote`，B 级没有 `conditions` | 打回 P2 |
| 镜头比样板密 | 一个镜头塞两个机制 | 一个镜头一个要点；20–40 秒 |
| 分镜写死秒数 | "2.5 秒后出现" | 回脚本加 cue |
