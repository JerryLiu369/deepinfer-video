# 10 验收清单

每道关卡的检查项。负责验收的人逐项打勾，结果写进对应的审校记录或 `STATUS.md` 备注。

## 通用规则（所有关卡）

- **审校记录要有证据。** 每一项"通过"都要写看了什么：镜头号、关键帧编号（`index.md` 里的帧号）、日志行或命令输出。只有"通过"二字的行视为没审。
- **零问题的记录要更严。** 一份审片/审稿记录报告 0 个问题时，必须逐镜头列出检查过的帧和项目；showrunner 验收时随机抽 3 个镜头复看。试点 EP07 的 visual/frames 两份记录都是 0 问题，而关键帧里至少有十几处重叠和小字——这样的记录打回重审。
- **自动检查不能代替人看。** `check_layout`、`lint_*`、`pacing_report` 无 WARN 只是入场条件。
- **人类检查点（H1–H4）只能由委托人本人通过。** 记录委托人的原话和时间。代理写的"无人值守授权""默认通过""代为确认"都无效；到达检查点时按 00 第 6 节停下。
- **改了目标要留痕。** 集时长、镜头数、三句话等任何对大纲/方案的偏离，先写进 `decisions.md`（集时长用"时长调整：EPxx …"开头，`lint_script.py` 会查），再改文件。
