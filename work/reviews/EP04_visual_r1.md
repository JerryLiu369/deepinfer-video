## 2. 镜头抽查与亮点评价

1. **S01 冷开场与 S03 目录全貌**：
   - 三层立体架构立面呈现自上而下的透视感，Python 编排层、C++ 核心与底层算子库比例协调，pybind11 虚线隔离带准确点明跨语言边界。
2. **S04 算子重心与双镜像**：
   - 左右两列对称文件树非常工整，中心动态派发器 ops.py 发出的双向连线具有很强的科技工业感。
3. **S05 血统环形图**：
   - 12.4% 的橙色切片与 87.6% 的蓝色主体形成强烈的视觉反差，有力支持了“外围胶水与自研核心”的论点。
4. **S12 共享内存环与 S16 错步流水线**：
   - 10 块环形共享内存槽位顺时针流转，红叉截断回程生动形象；S16 上下双时间轴重叠阴影区直观展现了 GPU 与 CPU 的并行掩盖。
5. **S18 CUDA Graph 分桶阶梯**：
   - 阶梯状分桶条与二分向上对齐动画精确表达了批次 Padding 的系统机理。
