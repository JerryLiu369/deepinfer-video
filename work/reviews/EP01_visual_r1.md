## 1. 核心视觉核查点

1. **字幕安全区保障**：
   - 全片 19 个镜头所有动态元素的底部边界均被严格控制在 $y \ge -2.7$，距离底部字幕烧录区（$y = -2.9$ 以下）保留了超过 0.2 单位的充足边距，硬字幕展示清晰无遮挡。
2. **文字与版式**：
   - 标题统一采用 20–24pt，正文说明统一采用 16–18pt，所有文字尺寸均 $\ge 16\text{pt}$，彻底消除了模糊与过小字。
   - 容器外框与文字层无嵌套重叠遮挡，`[dvlib] WARN` 清零（0 警告）。
3. **色彩语义系统**：
   - 预填充（Prefill）阶段与 Prompt 全程使用统一橙色（`#FF7B72`）。
   - 解码（Decode）阶段与生成 Token 全程使用统一蓝色（`#58A6FF`）。
   - 显存池与 KV Cache 全程使用统一绿色（`#3FB950`）。
   - 权重与 MoE 专家全程使用统一金色（`#D29922`）。
   - 带宽瓶颈、等待气泡与显存告警全程使用统一红色（`#F85149`）。
4. **关键帧构图表现**：
   - S07 算力天平（Scale）：砝码沉降与气泡上浮生动呈现了 5.0ms 访存与 0.032ms 算力的荒谬反差。
   - S08 批处理（Batching）：权重横流单次加载与下方 64 路槽位并行计算视觉传达直观透彻。
   - S11 静态木桶短板 vs S12 动态连续批处理：灰色气泡消除对比强烈。
