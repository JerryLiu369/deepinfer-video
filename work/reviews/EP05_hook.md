# EP05 冷开场盲选记录

- 评估人：viewer（委托人视角模拟）
- 候选版本：
  - **A 版（GPU 空泡与算力蒸发反差）**：以典型推理耗时（4 毫秒计算 vs 1.5 毫秒 CPU 停顿）切入，直击 25% 算力蒸发的现实痛点，引出“让 CPU 永远晚一步”的调度重叠机制。
  - **B 版（时间旅行悬念）**：以逆转时钟、违背因果律为比喻，提出在不知道前一个输出是什么的前提下提前送入下一个输入。

## 盲选评估与选择

- **入选版本**：**A 版（GPU 空泡与算力蒸发反差）**
- **理由**：
  1. A 版具有极强的技术冲击力。用 4 毫秒与 1.5 毫秒的具体对比，瞬间建立起读者对“算力蒸发近四分之一”的痛感，工业现实感极强。
  2. B 版的“时间旅行”比喻虽然有科幻戏剧感，但对于专业工程师和技术受众而言略显玄虚，且容易误导读者以为存在某种模型内部的超能力；A 版则实打实指向系统调度开销。
  3. A 版自然引出本集核心问题：“CPU 晚一步时，还没算出来的下一个词该怎么送进 GPU”，精准锁定下文展开的 TileLang `gather_input_ids_zos` 算子。
- **B 版保留元素**：
  - 将 B 版中关于“齿轮交错咬合”的机械隐喻吸收进 S04 镜头画面中，用来形象展示 GPU 前向与 CPU 后处理的流水线啮合。
