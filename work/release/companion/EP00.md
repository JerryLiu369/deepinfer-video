## 三句话

1. DeepInfer 是 DeepSeek 生产推理引擎的开源版本，只服务 V4.1-Flash，只做离线推理。（F00-02, F00-03）
2. 它的所有特色架构设计，都能追溯到三个源头：模型结构、部署形态与生产需求。（F00-07）
3. 全系列会跟随一个长上下文请求走完六大站点，每集剖析一站的核心机制与代价。（F00-08, F00-12）

## 本集的"为什么"

| 机制 | 源头（模型 / 部署 / 生产） | 换来什么 | 付出什么 |
| --- | --- | --- | --- |
| 仅支持单一模型 | 模型 + 生产 | 消除所有通用框架层层抽象，使调度器、算子与模型极致啮合 | 彻底丧失对其他任意模型的通用性 |
| 仅开源离线推理引擎 | 部署 + 生产 | 绕开与内部私有基础设施（如 3FS 存储集群与内部调度网关）的强耦合 | 社区无法开箱即用直接对外提供在线 API 云服务 |
| 宽专家并行超节点（EP64–128） | 部署 + 模型 | 大幅降低解码步骤的权重访存开销，显著提升大规模并发吞吐 | 对机间网络带宽与拓扑提出严苛要求，单机无法高效运行 |

<details>
<summary>自测题答案</summary>

1. 开源了离线推理引擎和核心优化算子；未包含在线云服务所需的 KV cache 系统、E/P/D 分离部署机制以及副本负载均衡。（S04 / F00-02, F00-03）
2. 放弃通用兼容性换取了与单一模型结构的极致协同，使引擎可以针对 YOCO 共享 KV、SWA 滑动窗口等模型特征定制调度与内核，无抽象层开销。（S03 / F00-02, G-02）
3. 绿色代表“开源代码里有”，可以在开源仓库源码中直接找到；琥珀色代表“仅文档描述·未开源”，表示仅在官方文档中有架构描述，代码未开源。（S07, S08 / F00-10）
4. 设定了约 6 万 token 的输入上下文；因为长前缀请求能同时触发长前缀命中、SWA 有界重放、宽专家并行与结构化输出等所有核心机制。（S10 / F00-08）
5. 依据是固定 commit 9bd9cf2 的开源源码静态剖析与官方一手公开文档，并没有在真实 SM100 或昇腾硬件上运行实测。（S06 / F00-11）
