# EP09 投机解码：DSpark 只验证值得验证的

本集深度剖析 DeepInfer 投机解码系统的动态变长验证机制（DSpark）与并行草稿（DFlash）。

## 关键技术点
1. **DFlash 并行草稿**：采用单次块并行前向而非串行自回归，利用非因果双向注意力及轻量 Markov 偏置修正，解耦草稿延迟。
2. **DSpark 动态验证**：基于吞吐剖面测绘，建立全局预算竞争机制，根据 token 生存概率在线剪裁验证前缀。
3. **物理瓶颈**：变长验证在低负载下（16并发）受固定延迟地板限制产生负收益，在高负载（60并发）下跨越多个计算桶产生显著吞吐增益。
