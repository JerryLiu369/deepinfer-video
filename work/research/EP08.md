# EP08 研究简报：并行：注意力用 DP，专家用宽 EP

## 1. 核心发现 (Key Findings)
1. **彻底摒弃张量并行 (No TP)**：在 DeepInfer 中，`ParallelConfig` 根本没有 `tensor_parallel_size`，`model_parallel_size` 直接绑定为 `context_parallel_size`。Attention 走纯数据并行（DP），MoE 走专家并行（EP），默认 `DP = EP`。全模型只有两种线性层：`ReplicatedLinear`（权重全卡复制）与 `ParallelRoutedLinear`（按专家切分）。
2. **异步批大小与步型投票 (Step-type Vote over Batch Sync)**：Attention DP 组各卡之间绝不同步 Batch 大小。C++ 调度器在每步仅通过一次 `MIN all_reduce` 投票决定当前是跑 prompt 还是 decode。孤立 rank 靠 1-token placeholder 占位步陪跑，以满足 EP 集合通信的拓扑对齐。
3. **MoE 六段流水与共享专家隐式融合 (6-stage Pipeline & Shared Expert Fusion)**：标准流水为 Gate -> DeepEP dispatch -> Grouped GEMM -> 共享专家计算（扣减通信 SM 限制）-> DeepEP combine（将共享专家结果作为 bias 传入归约 epilogue）-> 等待。共享专家完全不需要独立的 `all_reduce` 归约通信。
4. **两级贪心 EPLB 与 symm_mem 显存直读**：EPLB 在统计窗口内通过两级贪心逐层独立装箱：先给峰值热点逻辑专家追加冗余物理副本，再最小化历史各步最慢 rank 负载总和。在同 NVLink 域内通过 `symm_mem` 和 CUDA IPC 共享内存直接读取对端显存（单层镜像轮转），跨机才退回 NCCL 分桶 P2P。
5. **Mirror CP (Zigzag 镜像平衡)**：上下文并行通过 zigzag 映射切分 $2 \times cp$ 块，每卡分配对称的两块，使每个 rank 承担的因果注意力可见 Key 总量严格相等（偏差 0%）。但在开源代码中 CP 仅用于长序列 Prefill，官方文档披露生产环境暂不启用 TP 与 CP。

## 2. 最反直觉的洞察 (Aha Moment)
**Wide-EP 到底买到了什么？**
从 EP8 扩展到 EP64 时，单卡本地路由专家数从 52 个急剧下降到 7 个，MoE 权重的理论 HBM 访存读取量减少了 **7.43 倍**！
然而，在官方 Pareto 扫描曲线中：
- 在并发仅为 8 的极低负载下，吞吐大幅提升 **52.9%**，每用户交互速度提升 35%；
- 但在并发达到 256 的高负载下，EP64 相较于 EP8 的吞吐提升收敛至仅剩 **5.0%**（26,100 vs 24,850 tokens/s/GPU）！
**原因揭秘**：在高并发下，全卡聚合 Batch 显著增大，系统早已脱离了纯 HBM 带宽受限区，瓶颈全面转移到了跨 64 卡的 All-to-All 集合通信开销与核函数发射延迟。Wide-EP 真正买到的是**低并发下的极速交互性与显存容量摊销**，而非高并发下的峰值吞吐翻倍！

## 3. 观众最容易误解的地方
- **误解 1**：“DeepInfer 既然用了 64 卡，一定有 TP8 或者 TP4。”
  - **真相**：完全没有 TP。开源代码连 TP 配置项都没有。
- **误解 2**：“各个 DP rank 的 Batch 必须整齐划一，否则不能做集合通信。”
  - **真相**：DeepEP 是变长通信，各卡 Batch 随意，甚至没活的卡跑 1-token 假请求陪跑，只需步数对齐。
- **误解 3**：“EPLB 重排是在线动态给网络发权重消息。”
  - **真相**：同机内是显存直接镜像读取（IPC 直接拷内存），跨机才走 NCCL，且周期高达 1,000~10,000 步。

## 4. 重点可视化素材
- **Attention DP 与 EP-MoE 数据流立面图**：QKV 本地算 -> Gate 算 Top-K -> Token 跨卡飞散 (Dispatch) -> 本地专家算 GEMM -> Token 飞回原卡 (Combine)。
- **C++ 调度器投票与 1-token 占位陪跑步时序**：Rank 0 忙碌，Rank 1 陪跑假 token，两者步调一致穿过 DeepEP。
- **Wide-EP 访存天平 vs 通信收敛曲线图**：权重访存骤降 7.4 倍与高并发 5% 吞吐收敛的剧烈对比。
- **Mirror CP Zigzag 几何图**：阶梯三角形被切分成互补配对矩形。
