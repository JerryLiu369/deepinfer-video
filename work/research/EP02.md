## 1. 最重要的 3–5 个发现

1. **开源范围严格限定为“离线推理框架”**：DeepInfer 不是通用服务，官方明确声明它只支持单一模型（DeepSeek-V4.1-Flash），只支持两套指定硬件（NVIDIA SM100 与华为昇腾 Ascend 950），且仅提供离线批处理推理能力（F02-01, G-02, G-05）。
2. **完整在线云服务“缺三样关键基建”**：官方 README 自己列出了缺件清单——分布式 KVCache 存储管理系统、VE/Prefill/Decode 三段物理分离部署、以及跨数据并行（DP）副本的负载均衡器；这些组件因与内部基础设施强耦合而未开源（F02-03, F02-11）。
3. **官方生产系统是 E/P/D 三段分离 + 独立 3FS 存储**：Prefill 采用算力受限的标准 8 卡机（EP2–8），Decode 采用 64–128 卡宽专家并行超节点（EP64–128），最小高效服务单元为 128 张 GPU（64P + 64D）；KV 存储要求留存 72 小时以上，每张在线 GPU 对应约 14.4 TB 逻辑存储（F02-04, F02-05）。
4. **仓库里留有完整的“架构插槽”与调度接缝（Aha时刻）**：开源代码虽然没有跨机网络传输和存储读写实现，但完整预留了 `EngineType`（NORMAL/PROMPT/COMPLETION 三态）、7 个空虚函数、C++ 调度移交逻辑（`prefill_engine ... will be transferred to complete_engine`）以及显存状态复制缓冲区 `copy_state`；README 所述“大部分引擎功能已实现”指的正是这些插槽和单机调度核心，而非跨机搬运（F02-07, F02-08, F02-09）。
5. **外部协议与编解码由独立仓库 deepseek-recipe 承载**：OpenAI/Anthropic 协议转换、防特殊 Token 注入机制、流式 DSML 解析与图片预处理全在 Rust 开发的 deepseek-recipe 独立库中，与 DeepInfer 引擎进程物理解耦（F02-10）。

## 3. 观众最容易误解的地方

| 误解 | 真相 | 事实 ID |
| --- | --- | --- |
| 以为 git clone 下来就能直接部署一个兼容 OpenAI 的 API 在线服务 | 开源仓库只有离线推理入口（`LLM.generate`），没有 HTTP 服务与路由，在线服务所需的 Entrypoint、KV 存储与三段分离均未开源 | F02-01, F02-03, F02-10 |
| 以为每天 155 万亿 Token、每 GPU 小时 38 美元是净利润或人人可复制的成绩 | 38 美元是官方在单一生产集群、按谷时优惠定价计算的“整体营收”（Revenue），并非利润；155 万亿 Token 是建立在专用大规模集群与 3FS 软硬件一体化上的 | F02-06, `calc/EP02_capacity.py` |
| 以为 DeepInfer 是像 vLLM 一样能跑 Llama、Qwen 等任意开源模型的通用框架 | DeepInfer 深度针对 DeepSeek-V4.1-Flash 的架构（YOCO、40层SWA、MTP、宽EP）定制，官方不提供其他通用模型支持 | F02-01, F02-02 |

## 5. 可视化素材

- 时序步骤：
  1. 架构总览展开：Entrypoint 接收请求 -> 协议解析（recipe）-> 命中查询 -> 路由分发给 VE / Prefill / Decode -> 3FS 集中式 KV 读写。
  2. 开源范围高亮：框出 Prefill 和 Decode 容器内部的“DeepInfer Engine”，其余外部网络与存储框灰底标注“未开源”。
  3. 插槽机制拆解：展示 `EngineType` 枚举切换，展现 `init_pd_split`、`send_processed_prompts`、`should_copy_state` 等虚函数骨架。
- 数据表（附 calc 脚本 `work/calc/EP02_capacity.py`）：
  - 生产吞吐：155 万亿 token/天，平均 179.4 万 token/秒；每卡每小时 38 美元营收。
  - 最小高效部署单元：128 GPU（64P + 64D），对应逻辑 KV 存储约 1,843.2 TB（~1.84 PB）。
  - 单 3FS 存储机：20 块 30.73 TB NVMe SSD（裸容量 614.6 TB），读 40 GB/s / 写 5 GB/s（读写比 8:1）。
  - 跨机房带宽预算：每 8 张卡 400 Gbps（平均 50 Gbps/卡）。
- 结构关系：
  - 完整在线服务 vs 开源离线引擎对照表。
  - 生产拓扑三段（E/P/D）与计算卡型/并行度对比表。
